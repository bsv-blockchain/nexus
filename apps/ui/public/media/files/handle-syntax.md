# Handle syntax notes

`@handle@ecosystem` — the ecosystem separator is `@`, not `:`.

- A dot in the ecosystem part means a domain; no dot means an alias.
- A leading `@` decides the form before paymail is considered.
- Numeric ecosystems address the same identity two ways:
  `@23@treechat` and `@thoth@treechat`.

See docs/brc-feedback.md for the full write-up.
